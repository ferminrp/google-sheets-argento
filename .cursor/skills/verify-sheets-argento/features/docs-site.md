# Docs site

The docs site is the public landing for install steps, formula catalog, FAQ, changelog, and the static CEDEAR API. Users open GitHub Pages; locally the same files are served from `docs/` on loopback.

## Sub-features

- `docs-home-title` serves `index.html` with title Google Sheets Argento.
- `docs-install` shows `#instalacion` and the first-try formula `=DOLAR("blue")`.
- `docs-catalog` shows `#funciones` titled Catálogo de funciones, including DOLAR and CEDEAR.
- `docs-api-section` shows `#api` and a link to `api/cedears.json`.
- `docs-changelog` serves `/changelog.html`.
- `docs-cedears-api` serves `/api/cedears.json` as the build envelope.

## How to get to it (user POV)

- Production: `https://ferminrp.github.io/google-sheets-argento/` and `/changelog.html`.
- Local: `http://127.0.0.1:${VERIFY_DOCS_PORT}/` after launch (`python3 -m http.server` on `docs/`).
- Nav links: `#que-hace`, `#instalacion`, `#uso`, `#funciones`, `#api`, `#fuentes`, `#faq`, `changelog.html`.

## Driving it with verify-sheets-argento

Preconditions:

- `helpers/verify.sh doctor` prints `DOCTOR_OK`.
- The process bound to `VERIFY_DOCS_PORT` is this run’s `python3 -m http.server` serving `${REPO_ROOT}/docs`.

- **Home.** Run `.cursor/skills/verify-sheets-argento/helpers/verify.sh drive docs-site`. GET `/` is 200 and the body contains `<title>Google Sheets Argento`.
- **Install.** Same response contains `id="instalacion"` and `=DOLAR("blue")`.
- **Catalog.** Same response contains `id="funciones"` and `Catálogo de funciones`.
- **API section.** Same response contains `id="api"`.
- **Changelog.** GET `/changelog.html` is 200 and the body contains `Changelog`.
- **CEDEAR JSON.** GET `/api/cedears.json` is 200; JSON `schema_version` is `1`, `name` is `cedears`, `count` ≥ 1.
- **Proof.** Files under `${VERIFY_PROOF_DIR}/docs-site/` include `http-index.html`, `http-changelog.html`, `http-cedears.json`, and `meta.txt` listing the three HTTP entry points.

## Gotchas

- Serve `docs/`, not the repo root. A directory listing of `src/` is the wrong tree.
- Hero “live” cells in `script.js` fetch third-party APIs in the browser. A `curl` of `/` will not show those numbers. Do not treat skeleton HTML as a failed quote.
- `docs/api/cedears.json` is generated by `npm run build`. Stale Pages vs disk is a CI concern (`git diff --exit-code docs/api/cedears.json`); local drive proves the served file for this working tree.
- Port `8080` is what `docs/README.md` suggests; this skill defaults to `8765` so a leftover 8080 server is not reused. Doctor must match this run’s PID.
- Do not wrap proof in a real browser unless you also still keep the curl artifacts. curl is the harness the helper implements.
